# PHOENIX-Self-Reconfiguring-Robotic-Car
A Self-Reconfiguring Robotic Car designed to detect wheel failure and adapt its movement using an intelligent mechanical and control system.

## Project Overview
PHOENIX is an innovative robotic car
designed to respond to wheel failure
and maintain mobility through a
self-reconfiguration mechanism.

## Objectives
- Detect wheel failure.
- Monitor vehicle conditions.
- Activate the reconfiguration mechanism.
- Improve mobility and reliability.

## Components
- Arduino / ESP32
- DC Motors
- Motor Driver
- Sensors
- Chassis
- Battery
- Mechanical Reconfiguration System

## Technologies Used
- Embedded C / Arduino IDE
- Robotics
- Sensors and Automation

## Future Scope
- Autonomous failure detection
- Smart mobility
- Advanced robotic control
